# Yuya’s Agent Plugins

A collection of plugins for coding agents. Each plugin has its own installation
instructions, usage guide, and requirements.

## Plugins

| Plugin | Description |
| --- | --- |
| [YES — Yuya’s Explainer Skills](plugins/yes/README.md) | Portable HTML explanations, slides, quizzes, narrated videos, and courses |
| [grasp](plugins/grasp/README.md) | Learning-science design and review for explainer content |

## Contributing

Each plugin lives under `plugins/<name>` with its own version and manifest.
The root marketplace catalogs register the available plugins.

- [Compatibility](docs/compatibility.md)
